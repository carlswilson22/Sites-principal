## Preparação do contrato

Comece pela [Base para contratação](base-para-contratacao.md). Ela reúne os
campos a decidir, os limites atuais e os critérios para preparar o anexo técnico.
**Ainda não há modelo contratado nem condições comerciais acordadas.**
Estes arquivos registram o produto demonstrado; não formalizam uma contratação.

| Documento | Finalidade |
| --- | --- |
| [Base para contratação](base-para-contratacao.md) | Preparar escopo, responsabilidades, entrega e aceite, com campos em aberto |
| [Funcionalidades dos modelos](funcionalidades-dos-modelos.md) | Inventário atual das telas e operações, com limites da demonstração |
| [Matriz de funcionalidades](matriz-de-funcionalidades.md) | Comparar modelos e permissões da equipe |
| [Modelos visuais](modelos-visuais.md) | Descrever as três propostas de apresentação |
| [Segurança e privacidade](politica-de-seguranca-lgpd.md) | Separar mecanismos existentes de requisitos para operação real |
| [Integrações](manuais-de-integracao.md) | Identificar dependências e trabalhos necessários para ativar serviços externos |

Ao preparar o contrato, registre a versão/commit dos anexos selecionados.
Mudanças futuras no repositório precisam ser avaliadas antes de alterar o
escopo acordado. Documentos operacionais e históricos não devem ser anexados
automaticamente como compromissos de entrega.
